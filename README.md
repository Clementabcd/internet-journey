# Internet journey

Projet créé avec **Sandbox**, un éditeur en ligne qui permet de coder, tester
et déployer sans installer d'outil localement.

## Technologies

React 18 + Vite.

## Utiliser ce projet en local

```bash
npm install
npm run dev
```

Puis ouvre l'URL affichée dans le terminal.

## Build de production

```bash
npm run build
```

## Déploiement

Ce projet peut être déployé tel quel sur la plupart des hébergeurs statiques
ou orientés Node :

- **Vercel** : importe ce dossier (ou son dépôt GitHub) sur
  [vercel.com/new](https://vercel.com/new) — la configuration est détectée
  automatiquement.
- **Netlify** : glisse-dépose ce dossier sur
  [app.netlify.com/drop](https://app.netlify.com/drop), ou importe le dépôt
  GitHub sur [app.netlify.com/start](https://app.netlify.com/start).
- **GitHub Pages** : nécessite un export statique (`npm run build`) si le
  framework le permet ; adapté aux projets purement statiques.

## Utiliser Git / GitHub

Si ce projet a été envoyé sur GitHub depuis Sandbox, un dépôt a déjà été créé
ou mis à jour avec l'historique de tes changements. Pour continuer en local :

```bash
git clone <url-de-ton-dépôt>
cd internet-journey
npm install
```
